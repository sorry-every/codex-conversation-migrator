v3.4

- 图形界面读取并展示本机 Codex 会话列表。
- 支持勾选一个、多个或全部会话导出。
- 支持只导出会话，或同时打包关联文件和文档。
- 支持在另一台 Windows 电脑恢复会话、列表标题及关联文件。
- 基于本机已有 v2.8 的稳定实现，保留完整性校验、恢复前备份和同 ID 跳过机制。
- 调整界面文字，使“读取会话列表 → 勾选 → 导出 → 恢复”的流程更清楚。
- 按会话 ID 合并多个续接记录，列表只显示一条并使用最新记录文件。
- 读取全局置顶会话 ID，置顶会话显示“置顶”状态并排在列表最前面。
- 更新时间改为会话 JSONL 中最后一条实际事件的时间，不再优先使用可能过期的 session_index 时间。
- 同一会话存在多段续接文件时，根据实际事件时间选择最新记录。
- 修复分页历史链迁移：列表仍按会话合并显示，但导出会包含该会话的所有 rollout 历史段。
- 恢复时保留历史段的原始文件名并逐段校验，避免 `missing source rollout`。
- 目标电脑已有同 ID 的不完整恢复结果时，会补齐缺少的历史链文件。
- 恢复改为后台执行，新增阶段状态提示，恢复大迁移包时窗口保持可操作，失败时显示具体失败阶段。
