Codex 会话选择迁移工具 v3.4
============================

这是 Windows 10/11 x64 图形界面程序，用于按会话选择性迁移 Codex 本地对话。
无需安装 Python；双击“Codex会话选择迁移工具-v3.4.exe”即可使用。

旧电脑导出
----------
1. 启动工具。它会自动读取当前用户 .codex 目录中的会话列表，按会话 ID 去重；置顶会话显示在最前面。更新时间取会话最后一条实际事件，并转换为本机时间。
2. 在列表中勾选需要迁移的会话；可使用“全选”一次选择全部。
3. 点击“导出勾选的会话…”。
4. 选择“是”会同时收集会话工作目录以及记录中仍存在的附件、文档和生成文件；
   选择“否”只导出会话记录。
5. 保存生成的 .codexpack.zip，并将它复制到另一台电脑。v3.4 会把一个会话背后的全部分页历史段放入同一个迁移包。

新电脑恢复
----------
1. 在新电脑安装并登录 Codex，然后完全退出 Codex 和所有 Codex 命令行窗口。
2. 运行本工具，点击“从迁移包恢复…”，选择旧电脑生成的 .codexpack.zip。
3. 按提示完成恢复。恢复期间会显示当前阶段和处理进度，窗口保持可响应；完成后再重新打开 Codex。
4. 工具会重建 Codex 左侧会话列表并恢复原会话名称。同 ID 会话不会覆盖已有正文；如果之前恢复的会话缺少分页历史段，v3.4 会补齐缺失文件。
5. 附件和工作文件恢复到目标电脑的 .codex\migrated-files，迁移会话中的旧电脑路径会改写到这里。

安全机制
--------
- 不导出 auth.json、账号令牌、设备 ID、插件及全局设置。
- 对话和关联文件均记录 SHA-256，恢复前验证完整性。
- 修改索引前在 .codex\migration-backups 中备份状态数据库和索引。
- 恢复使用 Codex App Server 重建列表；SQLite 修改使用事务并执行完整性检查。
- 关联文件模式排除 .git、node_modules、缓存和常见密钥文件。
- 单文件上限 2 GB，关联文件总量上限 8 GB，最多 100000 个文件。

限制
----
- 已删除、仅存云端、已经失效或无法读取的附件不能从本地恢复；跳过项目会写入迁移包内的“导出警告.txt”。
- Codex 没有公开稳定的本地迁移格式。若未来存储结构发生变化，本工具可能需要更新。
- 迁移包含有完整对话内容和可能的私人文档，请妥善保管。
- 当前版本支持 Windows 到 Windows。
- v3.2 及更早版本导出的迁移包可能只含会话的最后一段记录。遇到 `missing source rollout` 时，必须回到原电脑使用 v3.4 重新导出，再在目标电脑恢复新包。

“更换 Codex 数据目录…”用于选择非默认 CODEX_HOME。“修复列表和标题”可处理恢复后左侧列表不显示或标题异常。
